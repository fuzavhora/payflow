# Getting Started

## Prerequisites

- Node.js 20+
- pnpm 9+
- Docker Desktop or Docker Engine with Compose

## Install

```bash
git clone https://github.com/fuzavhora/payflow.git
cd payflow
git switch feat/payflow-foundation
pnpm install
cp env.example .env
```

## Start infrastructure

```bash
docker compose up -d postgres redis
```

Wait until PostgreSQL is healthy, then generate the Prisma client and create the local schema migration:

```bash
pnpm --filter @payflow/api prisma:generate
pnpm --filter @payflow/api exec prisma migrate dev --name init
```

The repository's Prisma schema is the source of truth. The initial migration generated by this command includes the composite tenant foreign key between PaymentIntent and Customer. For an existing local database created from an earlier schema, use a new migration after reviewing the generated SQL; do not use `prisma db push` as a substitute for a reviewed migration in shared environments.

## Seed a test merchant

Set the required merchant seed environment values in your shell, then run:

```bash
PAYFLOW_MERCHANT_NAME="Local Demo" PAYFLOW_MERCHANT_SLUG="local-demo" pnpm --filter @payflow/api seed:merchant
```

The generated test API key is printed once. Store it securely; only its hash is persisted. Never commit it or put it in browser-side code.

## Run the applications

```bash
pnpm --filter @payflow/api dev
pnpm --filter @payflow/web dev
```

API base URL: `http://localhost:4000/api/v1`  
Dashboard: `http://localhost:3000`

## Current functional scope

The API currently supports merchant API-key authentication, customer CRUD, and local PaymentIntent create/list/retrieve operations. Internal domain services implement state transitions and PaymentAttempt persistence, but no provider is connected. A successful PaymentIntent API response is not a payment authorization or settlement. The dashboard currently uses fictional sample data.

## Stop and reset

```bash
docker compose down
```

To delete local database and Redis data (destructive):

```bash
docker compose down -v
```
